### 4a 先按用例原文不带 init 脚本执行 -> 失败，与本次改动无关：
  Could not resolve org.snakeyaml:snakeyaml-engine:2.10 / io.pebbletemplates:pebble:3.2.4
  > No cached version available for offline mode
  原因：这两个 blossom 插件运行时依赖是经镜像仓库缓存的，Gradle 的离线缓存按来源仓库匹配；
  不带 init 脚本时仓库列表里没有镜像，缓存条目匹配不上。init 脚本只重定义仓库地址，
  --offline 保证零网络访问，因此用例第 4 步已更正为带 init 脚本。
