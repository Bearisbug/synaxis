Each withProperty and withProperties call allocated one byte array of the block name, which name() builds:
32 bytes for the 15 characters of minecraft:chest, 40 for minecraft:oak_stairs (20) and minecraft:redstone_wire
(23), with no String object counted around it (scalar replaced, as the byte counts show). After the change these
calls allocate nothing. fromState sets every property of the parsed state through withProperties, one name per
property: 96 bytes less for the chest (3 properties), 160 for the stairs (4) and 200 for the redstone wire (5).
fromStateId is unchanged.
