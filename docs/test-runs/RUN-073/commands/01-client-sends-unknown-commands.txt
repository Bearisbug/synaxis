## Conclusion
# The 26.2 client sends /synaxisnosuchcommand as a ServerboundChatCommandPacket (the engine's ClientCommandChatPacket),
# whether or not the declared tree has the root. The same holds for a command the tree leaves out
# because its condition refuses the player (stop without its node). So the server's UNKNOWN callback is reachable from
# the chat screen, and G7 of the playable script (DESIGN-PROD API-PROD-026) can check the synaxis:command-unknown answer
# as designed; no fallback to the answer of a command there but refused is needed.
