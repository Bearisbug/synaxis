# test on the 20 ms encoding budget of a shard (OverlayStore.java:67 PHASE_NANOS, :449 the deadline). awaitEncodings returns at the deadline
# (:559-574) and harvest leaves every encoding not done by then for the next tick (:586), as docs/DESIGN-M3.md API-M3-007 step 4 says. Most tests
# call tickEnd() once and then assert what the phase wrote (OverlayStoreTest.java:81 and :86 for the CI failure), so any encoding over 20 ms on a
# loaded machine fails them. Not a product defect: a flush before unload that waits a tick keeps the chunk loaded (readyToUnload() is false while
