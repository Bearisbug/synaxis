结论
  1. 单中心（5×5 快照上的 relightArea，单线程，不挂代理）：7,488～7,802 µs → 3,284～3,286 µs；
     每次分配 2,894,564～2,894,566 B → 2,894,535 B（不变）。
  2. 改前的热点是 LightEngine$Area.read 逐格经 WorldView#getBlock 取状态 id：基准里占 64.0% 的样本，
     TC-WORLD-139 的测试 JVM 里占重算线程 93.8% 的样本（LightEngine.java:147 那一行）。
  3. TC-WORLD-139 读到的 27～38 个中心/s 主要来自 Gradle 测试任务挂的 JaCoCo 代理：同一基准 3 线程并发时，
     不挂代理每次 7,593 µs，挂代理 62,342～65,979 µs；不挂代理跑 TC-WORLD-139，改前 107/s 档就是 106.9 个中心/s。
     改后挂代理 3 线程每次 7,363～7,983 µs，TC-WORLD-139（挂代理）107/s 档 34.8 → 106.9 个中心/s，
     relight_queue_p99_ms 29,998.5 → 60.3，relight_ms_p99 113.8 → 15.4。
  4. LightEngineVersionTest 的指纹不变，LightEngine.VERSION 仍是 1，不升版本。
