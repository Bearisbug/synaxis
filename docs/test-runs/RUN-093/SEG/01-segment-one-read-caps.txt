与 ChunkData.NETWORK_TYPE 同一上限（2,097,152），超限在分配数组之前抛 IllegalArgumentException，区块同样判 failed。
高度图本来就按 Heightmap.Type 个数读（与 ChunkData 一致），没有改。

方块实体表只有物化与读光照时才读（ChunkData.NETWORK_TYPE，RUN-092 起计数上限 1,048,576、预分配按剩余字节 / 5），
